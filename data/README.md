# Data

The dataset used in this project is not included in this 
repository due to file size and licensing constraints.

## How to get the data

1. Go to the Kaggle dataset page:  
   https://www.kaggle.com/datasets/vijayuv/onlineretail

2. Click **Download** (free Kaggle account required)

3. Save the file to this `data/` folder

4. The notebook expects the filename:  
   `OnlineRetail.csv`

## Dataset info

- **Source:** UCI Machine Learning Repository via Kaggle
- **Records:** 541,909 transactions
- **Period:** December 2010 – December 2011
- **Size:** ~45MB
